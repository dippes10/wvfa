# Landing page gallery images

These 5 SVGs are placeholder art (abstract/iconographic, not photos) for the
landing page's Apple Cards Carousel — see `src/lib/data/gallery.ts`.

To swap in real academy photos:

1. Add your image files here (e.g. `training.jpg`, `matchday.jpg`) — any
   format works (jpg/png/webp), portrait orientation looks best (roughly 3:4).
2. Update the `src` path for the matching entry in
   `src/lib/data/gallery.ts` to point at your new file.
3. Commit the images normally — there's no upload feature by design, so
   these are edited directly in the repo, same as any other static asset.

No code changes needed beyond the `src` path swap.
